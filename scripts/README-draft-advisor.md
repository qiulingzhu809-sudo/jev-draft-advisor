# Codex 草稿 Jev 建议浮层（macOS）

完整安装、权限、API Key 和隐私说明以根目录 [README.md](../README.md) 为准，使用前请阅读其中的剪贴板回退限制。

这是一个独立的菜单栏小工具，不是 Codex 内嵌插件。它不会创建任务、发送消息、点击模型菜单或修改草稿。只有你主动按快捷键时，它才读取当前聚焦的 Codex 输入框，把草稿发送给 TypeSafe/Jev 分类，并以浮层显示推荐模型和推理强度；最终选择仍由你在 Codex 中完成。

## 启动

在本项目根目录的 `.env` 中配置 `TYPESAFE_API_KEY=...`，然后运行：

```bash
npm run draft-advisor
```

首次运行会编译 Swift 小工具。请在 macOS「系统设置 → 隐私与安全 → 辅助功能」允许该程序读取当前输入框；如果授权后仍无法读取，退出并重新运行。项目 `.env` 已被 `.gitignore` 忽略，不要提交密钥。

在 Codex 输入框写好草稿，不要发送；保持光标在输入框，按 **Control + J**。浮层会给出类似 `gpt-5.6-sol · high` 的建议。菜单栏的 `Jev` 可用来退出工具。每个新问题都可以重新按一次快捷键。如果系统或其他软件已占用 Control + J，菜单栏工具会提示快捷键注册失败。

## 边界与隐私

- 草稿只在按键后读取，并会发送到 TypeSafe/Jev API；不要分析含密码、密钥或未脱敏个人信息的草稿。
- 不监听每次键入，不自动提交 Codex 消息、不自动切换模型，也不调用 Codex App Server 创建另一条对话。
- AX 读取失败时会模拟全选和复制，临时使用剪贴板并尝试恢复。剪贴板历史工具可能保留草稿，异常退出或并发复制可能干扰恢复。
- 仅适配 `com.openai.codex` 及其辅助进程。应用已聚焦不保证光标在草稿框：复制回退可能误读并发送搜索框或历史消息文本，当前没有发送前预览。请先点击草稿框，不要用于敏感内容。
- 推荐规则和价格档位沿用 `scripts/codex-router.mjs`；价格只是公开档位，不是本次任务的准确费用。
- 当前浮层显示在鼠标附近，而非注入 Codex 输入框内部；这是独立小工具可实现的边界。

如需单独测试 Jev 接口，可以运行：

```bash
printf '%s' '{"prompt":"解释什么是意图识别"}' | node --env-file=.env scripts/advise-draft.mjs
```
