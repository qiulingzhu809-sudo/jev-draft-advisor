# Jev × Codex 一次性智能发送

本地网页输入任务 → Jev 分类 → 根据任务与偏好推荐模型、推理强度 → 查询当前 Codex 账号可用选项 → 创建 Codex 任务并发送首条消息。之后请在 **Codex 桌面版任务列表**打开该任务，使用原生对话框继续交流。网页不再提供多轮聊天、历史对话或继续回复功能，也不会读取或修改 Codex 桌面原有输入框。

## 启动与使用

在仓库根目录执行 `npm run smart-compose`，打开终端显示的 `http://127.0.0.1:8787`。需要 Node.js 20.6+、已登录的 `codex` CLI，以及仅保存在本地 `.env` 中的 `TYPESAFE_API_KEY`。可用 `SMART_COMPOSE_PORT` 更改端口。

1. 输入任务，选择成本/质量偏好，确认目标项目的绝对路径；默认工作目录是本仓库，仅适合测试。
2. 点击“智能发送”直接选型并发起任务，或先分析并人工核对模型、强度。高风险判断总是暂停等待人工确认。
3. 页面显示任务 ID、任务标题和首轮运行状态。首轮如果出现命令或文件修改审批，仍须在此页处理，不要在首轮完成前关闭页面或本地服务。
4. 等页面显示“本地会话已释放”，再在 Codex 桌面版任务列表按标题打开新任务，以后只在 Codex 原生对话框里回复。当前没有经过验证的网页到桌面任务自动跳转能力，因此不会声称已经自动打开。

网页仅绑定 `127.0.0.1`，有同源和 CSRF 检查。TypeSafe 密钥仅供服务端使用；网页不保存任务草稿、历史消息或任务 ID。Codex 仍按自身机制保存任务历史。请勿输入密码、密钥或未经脱敏的个人信息。

这并非完整的“原生接管”：首轮由本地 App Server 客户端发起，审批仍由该客户端接收；首轮完成后服务会关闭该 App Server 连接，下一次发送时再重新连接。网页只支持命令执行和文件修改两种审批，其他交互会明确失败，不会自动批准。若你在桌面任务列表里看不到任务，不要在网页重复发送，请先核对任务 ID 和账号。

模型推荐是启发式，并非实测最优：先满足任务复杂度对应的最低能力档，再参考公开 Codex credit 费率；`quality` 会提高一档。当前 `balanced`、`cost`、`speed` 均选最低满足档，因为尚无个人任务的延迟和成功率基准。参考：[Codex 定价](https://learn.chatgpt.com/docs/pricing)、[Codex App Server](https://learn.chatgpt.com/docs/app-server)。
